# Информационная система управления учебным процессом

Веб-приложение для управления учебным процессом с поддержкой множественных ролей пользователей.

## Установка и запуск

### Требования
- Python 3.9+
- pip

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск приложения

```bash
python main.py
```

или

```bash
uvicorn main:app --reload
```

Приложение будет доступно по адресу: `http://localhost:8000`

## Роли и доступ

### Administrator (Администратор)
- Полный доступ ко всем разделам
- Управление пользователями
- Просмотр журнала действий

### Dean_office (Сотрудник деканата)
- Управление студентами, группами, преподавателями
- Управление дисциплинами и расписанием
- Ввод аттестации
- Просмотр аналитики

### Teacher (Преподаватель)
- Просмотр своих дисциплин и расписания
- Ввод результатов аттестации
- Просмотр своих студентов

### Student (Студент)
- Просмотр своего расписания
- Просмотр своих оценок
- Просмотр документов

### Management (Руководство)
- Просмотр аналитики и отчетов
- Просмотр результатов обучения

## Проверка основных сценариев

### Сценарий 1: Добавить студента
1. Войти как dean (логин: dean, пароль: dean123)
2. Перейти в "Справочники" - "Студенты"
3. Нажать "Добавить студента"
4. Заполнить форму и нажать "Добавить"

### Сценарий 2: Создать группу
1. В "Справочники" - "Группы"
2. Нажать "Добавить группу"
3. Указать название

### Сценарий 3: Составить расписание
1. В "Учебный процесс" - "Расписание"
2. Нажать "Добавить занятие"
3. Выбрать группу, дисциплину, преподавателя

### Сценарий 4: Ввести оценки
1. Войти как teacher
2. Перейти в "Аттестация" - "Ввод результатов"
3. Выбрать студента и оценку

### Сценарий 5: Посмотреть ведомость
1. В "Аттестация" - "Ведомости"
2. Выбрать группу и дисциплину

### Сценарий 6: Просмотреть аналитику
1. Войти как management или admin
2. Перейти в "Аналитика"
3. Просмотреть статистику и списки

### Сценарий 7: Проверить журнал действий
1. Войти как admin
2. Перейти в "Администрирование" - "Журнал действий"
3. Просмотреть историю всех действий

### Сценарий 8: Проверить ограничения доступа
1. Войти как student
2. Убедиться, что видны только разделы "Расписание", "Мои оценки", "Документы"
3. Попытаться открыть /admin - должна быть ошибка доступа

## Структура БД

### Основные таблицы:
- users, roles, user_roles - Аутентификация
- students, groups - Студенты
- teachers, departments - Преподаватели
- disciplines - Дисциплины
- group_disciplines, teacher_disciplines - Связи
- schedules - Расписание
- attestations - Оценки
- action_logs - Журнал действий

## Технологический стек

- FastAPI, Uvicorn - Backend
- SQLite, SQLAlchemy - Database
- Jinja2 - Templates
- Session-based Auth с bcrypt
